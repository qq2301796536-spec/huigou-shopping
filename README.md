# 慧购分析助手官网

这是独立个人商品比价辅助项目的静态官网，当前提供手动价格与重量比较。多多客商品搜索、评论采集及个人结算价检查尚未接入。

## 免费部署

使用 GitHub Pages，公开仓库的 main 分支根目录作为发布来源。网站首页为 index.html，官方应用创建表单可根据实际托管地址填写官网链接。

## 文件

- index.html：主页及浏览器内手动单价比较工具
- privacy.html：隐私与使用说明
- callback.html：静态预留链接。**没有实现 OAuth 等授权回调处理。**
- app-icon.png：260×260 PNG 中性标识

## 安全

不要向此公开仓库提交多多进宝 Client Secret、Cookie、个人账号数据或其他凭证。真实 API 调用必须放在受保护的服务端，网站静态页面不能保存密钥。
