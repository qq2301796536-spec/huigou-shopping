隐私与使用说明

更新时间：2026 年 9 月 27 日

1. 当前版本

慧购分析助手目前是独立开发中的个人商品比价辅助工具。公开站点提供手动输入价格和重量并在浏览器中计算单价的功能。实时商品搜索已经通过获授权的多多客接口上线，目前覆盖接口可查询的可推广商品；所显示价格和优惠券为查询时参考信息。评价分析和登录账号结算价核对尚未提供。

2. 输入数据

手动比价中输入的名称、价格和重量仅存于当前浏览器页面的内存，离开或刷新页面即清空。本站不设置用户账号，不收集买家评论，不要求提供任何电商平台账号、密码或 API 密钥。用户主动输入的商品关键词会通过独立的 Cloudflare Worker 后端转发给获授权的拼多多多多客接口，后端仅在短暂的内存窗口中使用请求 IP 做限流；手动比价的输入不会上传。

3. 托管与基础日志

本站使用 GitHub Pages 托管静态页面；实时搜索使用 Cloudflare Workers 转发授权请求。两家托管服务及电商平台可能依据自身政策处理访问日志和请求信息，详见各自官方隐私政策。

4. 价格及推荐

手动比价由用户自行输入。商品搜索中的价格与优惠券为查询时参考信息，仅覆盖接口允许的可推广商品，不是全平台价格、完整评价或用户最终结算价。请以商家结算页面实际显示的价格、规格、配送、优惠适用条件和售后条款为准。

5. 独立性

本项目是独立个人工具，未经授权不代表拼多多或其他电商平台。
